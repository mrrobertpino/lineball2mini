Lesson Vocabulary

Machine learning
A process where an algorithm uses data to adjust a model’s parameters.
Linear classifier
A model that combines weighted features into a score to predict one of two classes.
Feature
A piece of information the model checks. Our features have yes/no values.
Weight
A parameter controlling the direction and strength of a feature’s contribution to the score.
Label
The class supplied as the expected answer for an example.
Training dataset
Labeled examples the algorithm uses to adjust the model’s weights.
Training algorithm
The procedure that uses training examples to update weights.
Learning rate
The size of a training update. This lab uses 1.
Epoch / training round
One complete pass through the training dataset.
Test dataset
Separate labeled examples used to check predictions without updating weights.
Inspect
Examine individual predictions, scores, and errors.
Evaluate
Judge the model’s performance using evidence and decide what to investigate next.
